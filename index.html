Adicionar NFs

Uma por linha. Pode colar direto do Excel. Aceita:

  • Número da NF — ex.: 130516
  • Chave da NF-e (44 dígitos) — funciona mesmo sem senha
  • Pedido — prefixe com P: — ex.: P:A2341232B
  • Ou use 📄 Importar XML / ZIP / Excel — também dá para arrastar os arquivos para a página
